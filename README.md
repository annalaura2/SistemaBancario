# 💰 Sistema Bancário em Python

Este é um projeto de estudo que simula as operações básicas de um sistema bancário utilizando a linguagem Python. O objetivo é implementar de forma simples as funcionalidades de **depósito**, **saque** e **extrato**, respeitando algumas regras de negócio.

## 🚀 Funcionalidades

- Depósito de valores com validação
- Saque com as seguintes regras:
  - Máximo de 3 saques por dia
  - Limite de R$ 500 por saque
  - Verificação de saldo
- Emissão de extrato com:
  - Histórico de movimentações
  - Saldo atualizado

## ⚙️ Tecnologias Utilizadas

- Python 3.x
- Biblioteca `datetime` (interna do Python)
